# Manim-Presentations
Subjects presentations made with Manim engine (3Blue1Brown)

Please read [manim repository](https://github.com/3b1b/manim) for use and installation tips.

How to compile for `.mp4`: `python3 -m manimlib your_file.py YourScene -w`

`pip install manim-slides`
`pip install "manim-slides[pyside6]"`
`manim-slides render --GL nome_do_seu_arquivo.py Bubble1`
`manim-slides present Bubble1`
