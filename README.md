# Manim-Presentations
Subjects presentations made with Manim engine (3Blue1Brown)

Please read [manim repository](https://github.com/3b1b/manim) for use and installation tips.

Install dependencies with: `pip install -r requirements.txt`
You may need to install: `pip install "manim-slides[pyside6]"`
How to compile for `.mp4`: `python3 -m manimlib your_file.py YourScene -w`
How to compile slides: `manim-slides render --GL nome_do_seu_arquivo.py Bubble1`
How to present slides: `manim-slides present Bubble1`
